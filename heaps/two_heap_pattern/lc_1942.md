# Smallest Chair — LeetCode 1942

## Approach: Sorting + Two Min-Heaps

The goal is to find the **smallest-numbered chair assigned to `targetFriend`**.

Each friend has:
- Arrival time: `times[i][0]`
- Leaving time: `times[i][1]`
- Original friend number: `i`

We process friends in **ascending order of arrival time**. Before assigning a chair to an arriving friend, we release the chairs of friends who have already left.

## 1. Preserve Each Friend's Original Number

If we sort `times` directly, the rows change positions. After sorting, the loop index `i` represents the friend's position in arrival order, not their original friend number.

To avoid losing the original number, we create a separate `vector<vector<int>>` called `friends`:

```cpp
vector<vector<int>> friends;

for (int i = 0; i < n; i++) {
    friends.push_back({times[i][0], times[i][1], i});
}
```

Each entry stores three values:

```text
{arrival time, leaving time, original friend number}
```

For example, suppose:

```cpp
times = {{99999, 100000}, {1, 2}};
```

Before sorting, the `friends` vector contains:

```text
{99999, 100000, 0}
{1, 2, 1}
```

After sorting by arrival time:

```text
{1, 2, 1}
{99999, 100000, 0}
```

Notice that the original friend number travels with the friend's arrival and leaving times. Therefore, we can still identify the target friend after sorting:

```cpp
if (friends[i][2] == targetFriend)
```

Here:
- `i` is the position in arrival order.
- `friends[i][2]` is the original friend number.

**This lets us process friends chronologically without losing their identities.**

## 2. Min-Heap 1: Available Chairs

```cpp
priority_queue<int, vector<int>, greater<int>> chairs;
```

This min-heap stores the numbers of all currently available chairs.

- Initially, all chairs from `0` to `n - 1` are available.
- `chairs.top()` returns the smallest available chair number.
- When a chair is assigned, we remove it using `chairs.pop()`.
- When a friend leaves, their chair is returned to this heap.

We use a min-heap because the problem asks for the **smallest-numbered available chair**.

## 3. Min-Heap 2: Seated Friends

```cpp
struct Compare {
    bool operator()(const vector<int>& a, const vector<int>& b) {
        return a[1] > b[1];
    }
};

priority_queue<vector<int>, vector<vector<int>>, Compare> people;
```

This min-heap stores the friends who are currently seated.

Each entry contains:

```text
{arrival time, leaving time, assigned chair}
```

The comparator orders friends by their leaving time, so:

```cpp
people.top()
```

gives the friend who leaves the earliest.

We use this heap to determine which chairs become available when a new friend arrives.

## 4. Algorithm

For each friend in the sorted `friends` vector:

**Step 1 — Release occupied chairs**

```cpp
while (!people.empty() && people.top()[1] <= friends[i][0]) {
    chairs.push(people.top()[2]);
    people.pop();
}
```

If a seated friend's leaving time is less than or equal to the arriving friend's arrival time, that friend has left.

We remove them from `people` and return their chair to `chairs`.

**Step 2 — Check whether this is the target friend**

```cpp
if (friends[i][2] == targetFriend)
    return chairs.top();
```

We release all chairs that have become available before checking the target.

The smallest available chair is therefore at `chairs.top()`.

**Step 3 — Assign a chair**

```cpp
int chair = chairs.top();
chairs.pop();

people.push({friends[i][0], friends[i][1], chair});
```

We assign the smallest available chair and store the newly seated friend in `people`, so their chair can be released when they leave.

## 5. Complexity Analysis

- **Time complexity: O(nlog n)**

  Sorting takes O(n log n). Each friend is inserted into and removed from the heap at most once, giving O(n log n) total heap operations.

- **Space complexity: O(n)**

  The `friends` vector and the two heaps require at most linear space.

## Key Takeaways

1. **Sort by arrival time** so friends are processed in the correct chronological order.
2. **Preserve the original friend number** by storing `{arrival, leaving, originalIndex}` in a separate vector.
3. **Use a min-heap for chairs** to obtain the smallest available chair.
4. **Use a min-heap for seated friends** to efficiently find who leaves earliest.
5. **Release chairs before checking the target**, ensuring the returned chair is the smallest one available when the target arrives.
