# 🔍 Find First and Last Position of Element in Sorted Array

## 🧩 Problem

Given a **sorted array** and a `target`, find:

* 📍 **First occurrence** of `target`
* 📍 **Last occurrence** of `target`

If the target doesn't exist, return:

```text
[-1, -1]
```

### Example

```text
nums = [5, 7, 7, 8, 8, 10]
target = 8

              ↓        ↓
nums = [5, 7, 7, 8, 8, 10]
                   3   4

answer = [3, 4]
```

---

# 💡 Main Idea

A normal binary search stops as soon as it finds the target.

But here, we **don't stop when we find it**.

Instead:

### To find the FIRST occurrence

When:

```cpp
nums[mid] == target
```

we store `mid`, but continue searching **towards the left**.

```text
        target
          ↓
[5  7  7  8  8  10]
          ↑
         mid

Found 8!

Could there be another 8 on the left?
YES → search left
```

So:

```cpp
ans1 = mid;
high = mid - 1;
```

---

### To find the LAST occurrence

When:

```cpp
nums[mid] == target
```

we store `mid`, but continue searching **towards the right**.

```text
[5  7  7  8  8  10]
          ↑
         mid

Found 8!

Could there be another 8 on the right?
YES → search right
```

So:

```cpp
ans2 = mid;
low = mid + 1;
```

---

# 🧠 Visual Intuition

Think of the two searches as:

```text
                 TARGET
                   ↓
        [ 8  8  8  8  8 ]
          ↑           ↑
        FIRST        LAST
```

The first binary search keeps asking:

> "I found an 8. Can I find an 8 even further LEFT?"

The second binary search asks:

> "I found an 8. Can I find an 8 even further RIGHT?"

---

# 1️⃣ Finding the First Occurrence

Code:

```cpp
while(low <= high){

    int mid = low + (high-low)/2;

    if(nums[mid] == target){
        ans1 = mid;
        high = mid - 1;
    }
    else if(nums[mid] < target){
        low = mid + 1;
    }
    else{
        high = mid - 1;
    }
}
```

## 🔎 Example

```text
nums = [5, 7, 7, 8, 8, 10]
target = 8
```

### Step 1

```text
low = 0
high = 5

mid = 2

[5  7  7  8  8  10]
       ↑
      mid
```

```text
nums[mid] = 7

7 < 8
```

Therefore, search right:

```text
low = mid + 1
```

---

### Step 2

```text
low = 3
high = 5

mid = 4

[5  7  7  8  8  10]
             ↑
            mid
```

```text
nums[mid] = 8
```

Found the target!

But this **might not be the first 8**.

So:

```cpp
ans1 = 4;
high = 3;
```

Search left.

---

### Step 3

```text
low = 3
high = 3

mid = 3

[5  7  7  8  8  10]
          ↑
         mid
```

Again:

```text
nums[mid] == 8
```

Store it:

```cpp
ans1 = 3;
```

And search even further left:

```cpp
high = 2;
```

Now:

```text
low = 3
high = 2
```

Loop stops.

Therefore:

```text
FIRST OCCURRENCE = 3
```

---

# 2️⃣ Finding the Last Occurrence

Now we perform another binary search.

The important difference is:

```cpp
if(nums[mid] == target){
    ans2 = mid;
    low = mid + 1;
}
```

When we find the target, we move **RIGHT**.

---

## 🔎 Example

```text
nums = [5, 7, 7, 8, 8, 10]
target = 8
```

### Step 1

```text
low = 0
high = 5

mid = 2

[5  7  7  8  8  10]
       ↑
      mid
```

```text
7 < 8
```

So:

```cpp
low = mid + 1;
```

---

### Step 2

```text
low = 3
high = 5

mid = 4

[5  7  7  8  8  10]
             ↑
            mid
```

Found:

```text
nums[mid] == 8
```

Store:

```cpp
ans2 = 4;
```

But there could be another 8 to the right.

So:

```cpp
low = mid + 1;
```

---

### Step 3

```text
low = 5
high = 5

mid = 5

[5  7  7  8  8  10]
                 ↑
                mid
```

```text
10 > 8
```

So search left:

```cpp
high = mid - 1;
```

Now:

```text
low = 5
high = 4
```

Loop stops.

Therefore:

```text
LAST OCCURRENCE = 4
```

---

# 🎯 Final Result

```text
FIRST SEARCH
      ↓
     ans1 = 3

SECOND SEARCH
      ↓
     ans2 = 4

              ↓
nums = [5  7  7  8  8  10]
                 └───┘
                  3  4

answer = [3, 4]
```


---

# ⭐ The Most Important Part

Remember this pattern:

### FIRST occurrence

```cpp
if(nums[mid] == target){

    ans = mid;

    high = mid - 1;  // ⬅️ GO LEFT
}
```

### LAST occurrence

```cpp
if(nums[mid] == target){

    ans = mid;

    low = mid + 1;   // ➡️ GO RIGHT
}
```

That's the entire trick.

---

# ⏱️ Complexity

We perform **two binary searches**.

Each binary search takes:

```text
O(log n)
```

Therefore:

```text
O(log n) + O(log n)
        = O(log n)
```

### Space

Only a few variables are used:

```text
O(1)
```

---

# 🧠 One-Line Memory Trick

```text
FIRST → Found target → GO LEFT
LAST  → Found target → GO RIGHT
```

Or simply:

```text
FIRST : high = mid - 1
LAST  : low  = mid + 1
```

The important idea is that **finding the target is not the end of the search**.
You save the current index and continue searching in the direction where a better answer could exist.
