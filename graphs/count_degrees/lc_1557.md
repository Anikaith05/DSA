# Minimum Number of Vertices to Reach All Nodes

## 🧩 Problem

Given a directed graph with `n` vertices labeled from `0` to `n - 1`, find the **smallest set of vertices** from which all other vertices can be reached.

---

## 💡 Key Idea

We only need to find the vertices with **in-degree `0`**.

### Why?

Consider:

```text
0 → 1 → 2
```

* `0` has **in-degree 0**
* `1` has in-degree 1
* `2` has in-degree 1

If we start from `0`, we can reach:

```text
0 → 1 → 2
```

But there is **no edge entering `0`**, so no other vertex can reach `0`.

Therefore, `0` **must be included** in our answer.

### General Rule

> A vertex with in-degree `0` cannot be reached from any other vertex, so it must be chosen as a starting vertex.

For every vertex with in-degree greater than `0`, there is some edge entering it. By repeatedly following incoming edges backward, we eventually reach a vertex with in-degree `0`.

Therefore, selecting **all vertices with in-degree `0`** is sufficient.

---

## 🔍 Approach

### Step 1: Calculate the in-degree of every vertex

Create an array:

```cpp
vector<int> count_in(n, 0);
```

For every directed edge:

```text
u → v
```

increase the in-degree of `v`:

```cpp
count_in[v]++;
```

---

### Step 2: Find all vertices with in-degree `0`

Traverse all vertices:

```cpp
for(int i = 0; i < n; i++){
    if(count_in[i] == 0){
        final_ans.push_back(i);
    }
}
```

These vertices must be included in the answer.

---

## 🧪 Example

Consider:

```text
0 → 1
2 → 1
3 → 4
```

In-degrees:

| Vertex | In-degree |
| ------ | --------- |
| 0      | 0         |
| 1      | 2         |
| 2      | 0         |
| 3      | 0         |
| 4      | 1         |

Therefore:

```text
Answer = [0, 2, 3]
```

Starting from these three vertices:

```text
0 → 1
2 → 1
3 → 4
```

All vertices are reachable.

---

## ⏱️ Complexity

Let:

* `V` = number of vertices
* `E` = number of edges

### Time Complexity

```text
O(V + E)
```

We process every edge once to calculate in-degrees and every vertex once to find the answer.

### Space Complexity

```text
O(V)
```

We store the in-degree array and the answer.

---

## 🧠 Important Insight

This problem **does not require DFS, BFS, or Kosaraju's algorithm**.

The key observation is simply:

```text
Directed Graph
      ↓
Find vertices nobody can enter
      ↓
In-degree = 0
      ↓
Those vertices must be starting points
```

### Remember

> **Minimum starting vertices = all vertices with in-degree 0.**
