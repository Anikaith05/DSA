# 🏙️ 1615. Maximal Network Rank

## 💡 Approach

The **network rank** of two cities is:

```text
degree[i] + degree[j]
```

But if `i` and `j` are **directly connected**, their shared road gets counted twice.

So:

```text
Network Rank
     │
     ├── Not connected → degree[i] + degree[j]
     │
     └── Connected     → degree[i] + degree[j] - 1
```

---

## 🔍 Step-by-Step

### 1️⃣ Calculate degree of every city

For every road `[u, v]`:

```text
degree[u]++
degree[v]++
```

Example:

```text
roads = [[0,1], [0,3], [1,2], [1,3]]

       0 ───── 1
       │     ╱ │
       │   ╱   │
       3 ───── 2

degree:
0 → 2
1 → 3
2 → 1
3 → 2
```

---

### 2️⃣ Store the adjacency list

```cpp
adj[u].push_back(v);
adj[v].push_back(u);
```

This lets us check:

> "Is city `i` directly connected to city `j`?"

Using:

```cpp
find(adj[i].begin(), adj[i].end(), j)
```

---

### 3️⃣ Check every pair of cities

For every `(i, j)`:

```text
                Are i and j connected?
                       │
              ┌────────┴────────┐
             YES               NO
              │                 │
       degree[i] +          degree[i] +
       degree[j] - 1        degree[j]
```

We then keep the maximum rank.

---

## 🧠 Why subtract 1?

Suppose:

```text
0 ───── 1
```

and:

```text
degree[0] = 2
degree[1] = 3
```

Adding them gives:

```text
2 + 3 = 5
```

But the road:

```text
0 ───── 1
```

belongs to **both** cities, so it was counted twice.

Therefore:

```text
5 - 1 = 4
```

---

## ⏱️ Complexity

Let `d` be the maximum degree of a city.

### Degree calculation

```text
O(E)
```

### Building adjacency list

```text
O(E)
```

### Checking all city pairs

There are:

```text
O(n²)
```

pairs.

For each pair, `find()` takes:

```text
O(degree[i])
```

So overall:

```text
O(n² × d)
```

Since the constraint is:

```text
n ≤ 100
```

this is easily fast enough.

### Space

```text
O(n + E)
```

for the degree array and adjacency list.

---

## 🧩 Key Pattern

The important observation is:

> **Don't build the union of roads for every pair.**

Instead:

```text
Degree of A
    +
Degree of B
    -
1 if A-B is an edge
```

This turns the problem into a simple **degree + adjacency lookup** problem.
