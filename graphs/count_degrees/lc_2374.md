# 🔗 2374. Node With Highest Edge Score

### 💡 Core Idea

For every node `i`:

```text
i ───────► edges[i]
```

The **edge score of `edges[i]` increases by `i`**.

So we can directly accumulate:

```text
scores[edges[i]] += i
```

---

## 🧠 Visual Example

```text
edges = [1, 0, 0, 0, 0, 7, 7, 5]

Node     Points to
 0   ───► 1
 1   ───► 0
 2   ───► 0
 3   ───► 0
 4   ───► 0
 5   ───► 7
 6   ───► 7
 7   ───► 5
```

Therefore:

```text
score[0] = 1 + 2 + 3 + 4 = 10
score[1] = 0
score[5] = 7
score[7] = 5 + 6 = 11   ← maximum
```

Answer:

```text
7
```

---

## ⚙️ Algorithm

### 1️⃣ Calculate every node's score

```cpp
for(int i = 0; i < n; i++) {
    scores[edges[i]] += i;
}
```

Think of it as:

```text
i ──► edges[i]

       ↓
scores[edges[i]] += i
```

### 2️⃣ Find the maximum score

Traverse `scores` from left to right.

```cpp
if(scores[i] > max_s) {
    max_s = scores[i];
    maxi = i;
}
```

Notice we use **`>`**, not `>=`.

That automatically handles the tie rule:

> If scores are equal, keep the smaller index.

Because we're checking indices from `0 → n-1`.

---

## 💻 Code

```cpp
class Solution {
public:
    int edgeScore(vector<int>& edges) {

        int n = edges.size();

        vector<long long> scores(n, 0);

        // Calculate edge scores
        for(int i = 0; i < n; i++) {
            scores[edges[i]] += i;
        }

        // Find node with maximum score
        int maxi = 0;
        long long max_s = 0;

        for(int i = 0; i < n; i++) {
            if(scores[i] > max_s) {
                max_s = scores[i];
                maxi = i;
            }
        }

        return maxi;
    }
};
```

---

## ⏱️ Complexity

```text
Time  : O(n)
Space : O(n)
```

We make **two linear passes** over the nodes.

### 🔑 Pattern to Remember

```text
Each node points somewhere
        ↓
Accumulate the source node's value
        ↓
scores[destination] += source
        ↓
Find maximum
```

This is essentially a **"reverse contribution" / aggregation by destination** pattern.
