# 🔺 1579. Minimum Degree of a Connected Trio

## 💡 Approach

A **trio** is a group of **3 cities where every pair is directly connected**.

```text
       i
      / \
     /   \
    j ─── k

i ── j ✅
j ── k ✅
k ── i ✅
```

We need to find the trio with the **minimum degree**.

---

## 🧠 Key Idea

We use two data structures:

```text
degree[i]       → number of roads connected to city i
adj[i][j]       → whether i and j have a direct road
```

The adjacency matrix gives us **O(1)** edge checking.

```cpp
adj[i][j] == 1
```

means:

```text
i ─── j
```

---

## 1️⃣ Build the Graph

For every edge `[u, v]`:

```cpp
adj[u][v] = 1;
adj[v][u] = 1;

degree[u]++;
degree[v]++;
```

Because the graph is **undirected**, both directions are stored.

---

## 2️⃣ Check Every Possible Trio

We choose:

```text
i < j < k
```

This avoids checking the same trio multiple times.

```text
(i, j, k)

       i
      / \
     /   \
    j ─── k
```

A trio exists if:

```cpp
adj[i][j] &&
adj[j][k] &&
adj[k][i]
```

Since the adjacency matrix provides O(1) lookup, checking a trio is constant time.

---

## 3️⃣ Calculate Trio Degree

The total degrees of the three cities include the **three internal trio edges twice**.

```text
       i
      / \
     /   \
    j ─── k
```

There are 3 internal edges:

```text
i ─ j
j ─ k
k ─ i
```

Each is counted once for each endpoint:

```text
3 edges × 2 = 6
```

Therefore:

```text
Trio Degree
= degree[i] + degree[j] + degree[k] - 6
```

---

## 🔄 Complete Flow

```text
        Build graph
             │
             ▼
   Calculate every degree
             │
             ▼
     Choose i < j < k
             │
             ▼
   ┌─────────────────────┐
   │ Are all 3 edges     │
   │ present?             │
   └─────────┬───────────┘
             │
        YES  │
             ▼
 degree[i]+degree[j]+degree[k]-6
             │
             ▼
       Update minimum
```

---

## ⏱️ Complexity

There are three nested loops:

```text
O(n³)
```

Each trio check is **O(1)** because of the adjacency matrix.

Therefore:

```text
Time:  O(n³)
Space: O(n²)
```

With:

```text
n ≤ 400
```

the approach is feasible.

---

## ⭐ Key Takeaway

The important optimization over using `find()` on an adjacency list is:

```text
Adjacency List + find()
        ↓
O(degree)

Adjacency Matrix
        ↓
O(1)
```

So for every possible trio, we can check all three connections instantly.
