# 🚦 Maximum Importance of Roads

### 💡 Core Idea

A city/node that appears in **more roads** should receive a **higher importance value**.

So the strategy is:

```text
Count connections
      ↓
Calculate degree of every node
      ↓
Sort nodes by degree
      ↓
Assign importance 1 → n
      ↓
Calculate total road importance
```

---

## 🧠 Example

Suppose:

```text
n = 5

roads = [
    [0,1],
    [0,2],
    [0,3],
    [1,2]
]
```

### 1️⃣ Calculate degrees

```text
Node:    0   1   2   3   4
Degree:  3   2   2   1   0
```

### 2️⃣ Sort nodes by degree

Your comparator sorts:

```text
degree ↑

4 → 0
3 → 1
2 → 2
1 → 2
0 → 3
```

So:

```text
sorted_nodes = [4, 3, 2, 1, 0]
```

### 3️⃣ Assign importance

```text
Node:        4   3   2   1   0
Importance:  1   2   3   4   5
```

Therefore, nodes with **higher degree get higher importance**.

---

## 🔑 Comparator

```cpp
bool operator()(const int& a, const int& b) {
    if (degree[a] == degree[b]) {
        return a > b;
    }

    return degree[a] < degree[b];
}
```

The important part:

```cpp
degree[a] < degree[b]
```

means nodes are sorted by **increasing degree**.

Then importance is assigned:

```cpp
rank[sorted_nodes[i]] = i + 1;
```

Therefore:

```text
lowest degree  → importance 1
      ↓
highest degree → importance n
```

---

## 🧮 Calculating Answer

For every road:

```cpp
total += rank[u] + rank[v];
```

Because the importance of a road is:

```text
importance(u) + importance(v)
```

Example:

```text
Road: [0, 1]

importance[0] = 5
importance[1] = 4

Contribution = 5 + 4 = 9
```

---

## ⏱️ Complexity

Let:

```text
N = number of nodes
E = number of roads
```

| Operation         | Complexity   |
| ----------------- | ------------ |
| Calculate degrees | `O(E)`       |
| Sort nodes        | `O(N log N)` |
| Assign ranks      | `O(N)`       |
| Calculate answer  | `O(E)`       |

### Overall

```text
Time:  O(E + N log N)
Space: O(N)
```

---

## ⚠️ Why `long long`?

Maximum answer can exceed the range of `int`.

```text
Maximum importance per node ≈ 5 × 10⁴

One road:
≈ 10⁵

5 × 10⁴ roads:
≈ 5 × 10⁹
```

But:

```text
INT_MAX ≈ 2.1 × 10⁹
```

So:

```cpp
long long total = 0;
```

is necessary.

---

## 📝 Pattern to Remember

This problem is essentially:

```text
Degree of node
      ↓
Sort nodes by degree
      ↓
Give largest values to largest degrees
      ↓
Sum values across edges
```

### ⭐ Key Insight

> **A node's importance should be proportional to how many roads connect to it.**
