# ⭐ Maximum Star Sum

**LeetCode 2497 — Maximum Star Sum of a Graph**

## 💡 Idea

For every node `i`, we want:

> **Node's value + the largest `k` positive-valued neighbors**

So instead of exploring every possible combination of neighbors, we:

1. Build an adjacency list.
2. Sort each node's neighbors by their `vals[]` value in **descending order**.
3. Take at most `k` positive neighbors.
4. Track the maximum star sum.

---

## 👀 Visual Example

Suppose:

```text
vals = [10, 2, 5, -1, 7]

        2
        |
        10 ─── 5
        |
       -1
        \
         7
```

For node `10`:

```text
Neighbors:
     2, 5, -1, 7

Sorted by value:
     7 → 5 → 2 → -1
```

If `k = 2`:

```text
Star = 10 + 7 + 5

     = 22
```

We ignore `2` and `-1` because we can only choose `k = 2` neighbors.

---

## 🔑 Key Observation

For a fixed center node:

```text
          neighbors
       ↙     ↓     ↘
     [7]    [5]    [2]    [-1]
      ↑      ↑
    choose these
```

There is **no reason to choose a negative neighbor**.

And among positive neighbors, we only need the **largest `k`**.

Therefore:

```text
Best Star(i)
    = vals[i]
    + top k positive neighbor values
```

---

## 🧩 Why the Comparator?

The adjacency list stores **node indices**, not their values.

Example:

```text
adj[i] = [3, 7, 2]

vals:
index 2 → 10
index 3 → 4
index 7 → 15
```

We want to sort:

```text
3, 7, 2
```

according to:

```text
vals[3], vals[7], vals[2]
```

So the comparator does:

```text
vals[a] > vals[b]
```

giving:

```text
15 → 10 → 4
```

---

## 🚀 Algorithm

```text
Build adjacency list
        ↓
For every node
        ↓
Sort its neighbors by vals[neighbor]
        ↓
Take first k positive neighbors
        ↓
Calculate star sum
        ↓
Update maximum
```

---

## ⏱️ Complexity

Let `dᵢ` be the degree of node `i`.

### Building graph

```text
O(E)
```

### Sorting neighbors

```text
O(Σ dᵢ log dᵢ)
```

Since:

```text
Σ dᵢ = 2E
```

the overall sorting cost is approximately:

```text
O(E log E)
```

### Calculating sums

```text
O(V + E)
```

### Overall

```text
Time:  O(E log E + V)
Space: O(V + E)
```

---

## 🧠 Pattern to Remember

This problem is essentially:

```text
Graph
  +
For every node
  +
Choose top K neighbors
  +
Ignore negative contributions
```

### General pattern

> **When a graph problem asks for the best `k` neighbors of every node, think: adjacency list + sorting/top-k selection.**
