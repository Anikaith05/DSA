# 2101. Detonate the Maximum Bombs

## Approach

The key idea is to convert the bomb problem into a **directed graph problem**.

Each bomb is treated as a **vertex**.

If bomb `i` can detonate bomb `j`, we create a directed edge:

```text
i → j
```

Then, starting from each bomb, we perform DFS to find how many bombs can eventually be detonated.

---

## 1. Build the Directed Graph

For every pair of bombs `i` and `j`, we check whether bomb `j` lies within the range of bomb `i`.

If it does:

```cpp
adj[i].push_back(j);
```

For example:

```text
0 → 1
0 → 2
2 → 3
3 → 4
```

This means:

* Bomb `0` can detonate bombs `1` and `2`
* Bomb `2` can detonate bomb `3`
* Bomb `3` can detonate bomb `4`

Therefore, detonating bomb `0` eventually detonates all 5 bombs.

---

## 2. Checking Whether One Bomb Can Detonate Another

Suppose bomb `i` has:

```text
(xi, yi, ri)
```

and bomb `j` has:

```text
(xj, yj, rj)
```

We only need to check whether the **center of bomb `j` is inside the range of bomb `i`**.

The distance between their centers is:

$$
d = \sqrt{(x_i-x_j)^2 + (y_i-y_j)^2}
$$

Bomb `i` can detonate bomb `j` when:

$$
d \le r_i
$$

Instead of calculating the square root, we square both sides:

$$
(x_i-x_j)^2 + (y_i-y_j)^2 \le r_i^2
$$

This is implemented as:

```cpp
bool inrange(int i, int j, vector<vector<int>>& bombs) {
    long long dx = bombs[i][0] - bombs[j][0];
    long long dy = bombs[i][1] - bombs[j][1];

    return dx * dx + dy * dy <=
           1LL * bombs[i][2] * bombs[i][2];
}
```

`long long` is used to safely handle the squared values.

---

## 3. DFS

Once the graph is constructed, we run DFS starting from every bomb.

For each starting bomb:

```cpp
vector<int> visited(n, 0);
int count = 0;

dfs(i, visited, adj, count);
```

Inside DFS:

```cpp
void dfs(int vertex, vector<int>& visited,
         vector<vector<int>>& adj, int& count) {

    count++;
    visited[vertex] = 1;

    for (auto node : adj[vertex]) {
        if (visited[node] == 0) {
            dfs(node, visited, adj, count);
        }
    }
}
```

### Why do we need `visited`?

The graph can contain cycles.

For example:

```text
0 → 1 → 2
    ↑   ↓
    └───┘
```

Without `visited`, DFS could keep going around the cycle forever.

`visited` also ensures that each bomb is counted only once.

---

## 4. Try Every Bomb as the Starting Bomb

We are allowed to initially detonate **only one bomb**.

Therefore, we try every bomb as the starting point:

```cpp
for(int i = 0; i < n; i++) {
    vector<int> visited(n, 0);
    int count = 0;

    dfs(i, visited, adj, count);

    max_count = max(max_count, count);
}
```

The DFS count represents:

> The total number of bombs that can eventually be detonated if bomb `i` is initially detonated.

We take the maximum among all starting bombs.

---

## Complete Flow

```text
Bomb coordinates
       ↓
Check every pair of bombs
       ↓
Can i detonate j?
       ↓
Yes → add edge i → j
       ↓
Construct directed graph
       ↓
Run DFS from every bomb
       ↓
Count reachable bombs
       ↓
Take maximum count
```

---

## Complexity

Let `n` be the number of bombs.

### Building the graph

We check every pair of bombs:

$$
O(n^2)
$$

### DFS

We perform DFS from every bomb.

Each DFS can take:

$$
O(V+E)
$$

Since there can be up to `O(n²)` edges:

$$
O(n^3)
$$

Overall:

$$
\boxed{O(n^3)}
$$

Space complexity:

$$
\boxed{O(n^2)}
$$

because the adjacency list can contain up to `n²` edges.

---

## Key Insight

The important observation is:

> **A bomb triggering another bomb can be represented as a directed edge.**

So the problem becomes:

> **For every vertex in a directed graph, find how many vertices are reachable from it using DFS, and return the maximum.**

This transforms a geometry problem into a standard **Graph + DFS + Reachability** problem.
