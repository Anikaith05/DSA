# Course Schedule — DFS Cycle Detection

A DFS-based solution for **LeetCode 207 — Course Schedule** using **3-state cycle detection** in a directed graph.

## Problem

Given:

* `numCourses` — number of courses
* `prerequisites[i] = [a, b]` — to take course `a`, you must first complete course `b`

Determine whether it is possible to finish **all courses**.

### Key Observation

Prerequisites form a **directed graph**:

```text
[a, b]

b → a
```

Therefore:

> **If the directed graph contains a cycle, it is impossible to finish all courses.**

```text
0 → 1 → 2
    ↑   ↓
    └───┘

❌ Cycle → Cannot finish
```

---

## Approach

Use **DFS with 3 states** for every vertex:

| State | Meaning                                  |
| ----- | ---------------------------------------- |
| `0`   | Unvisited                                |
| `1`   | Currently being processed / in DFS stack |
| `2`   | Completely processed                     |

### Cycle Detection

During DFS, for every neighbour:

```text
Neighbour = 0
    ↓
Explore it using DFS

Neighbour = 1
    ↓
🚨 Cycle detected

Neighbour = 2
    ↓
Already completely processed → Ignore
```

The important case is:

```text
visited[neighbour] == 1
```

because state `1` means that the neighbour is **still in the current DFS path**.

Example:

```text
A → B → C
    ↑   ↓
    └───┘
```

While processing `C`, we encounter `B`.

```text
visited[B] == 1
        ↓
     ❌ CYCLE
```

---

## Algorithm

1. Build the adjacency list from `prerequisites`.
2. Create a `visited` array initialized to `0`.
3. Run DFS from every unvisited vertex.
4. When entering a vertex:

   * Mark it `1`.
5. Visit all its neighbours:

   * `0` → recursively visit.
   * `1` → cycle found.
   * `2` → ignore.
6. After processing all neighbours, mark the vertex `2`.
7. If a cycle exists → return `false`.
8. Otherwise → return `true`.


## Complexity

Let:

* `V` = number of courses
* `E` = number of prerequisites

```text
Time:  O(V + E)

Space: O(V + E)
```

The adjacency list takes `O(V + E)` and the visited array + recursion stack take `O(V)`.

---

## Key Takeaway

```text
Directed Graph
      ↓
     DFS
      ↓
  3 States
      ↓
0 = Unvisited
1 = Processing  ← Seeing 1 = 🚨 Cycle
2 = Completed
```

> **For directed graphs, encountering a node that is still in the current DFS stack means there is a cycle.**
