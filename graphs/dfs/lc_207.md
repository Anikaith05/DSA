# Course Schedule — DFS Cycle Detection

## 🧠 Core Idea

`Course Schedule` is a **directed graph cycle detection** problem.

If:

```text
[1, 0]
```

it means:

```text
0 → 1
```

If we get:

```text
0 → 1 → 2 → 0
```

🔴 **Cycle → cannot finish courses**

If there is no cycle:

🟢 **Can finish all courses**

---

# 🔍 DFS Algorithm

We use **3 states**:

```text
0 = Never visited
1 = Currently in this DFS path
2 = Completely finished
```

### Example

```text
0 → 1 → 2
```

While DFS is running:

```text
0 = 1
1 = 1
2 = 1
```

After finishing `2`:

```text
0 = 1
1 = 1
2 = 2
```

After finishing `1`:

```text
0 = 1
1 = 2
2 = 2
```

Finally:

```text
0 = 2
1 = 2
2 = 2
```

### 🚨 Cycle detection

Suppose:

```text
0 → 1 → 2
    ↑     |
    └─────┘
```

While exploring `2`, we encounter `1`.

```cpp
visited[1] == 1
```

`1` is **still in the current DFS path**.

Therefore:

```text
🔴 CYCLE
```

---

# 💻 DFS Logic

```cpp
visited[vertex] = 1;        // currently exploring

for (every neighbor) {

    if (visited[neighbor] == 0)
        DFS(neighbor);

    else if (visited[neighbor] == 1)
        cycle = true;
}

visited[vertex] = 2;        // completely finished
```

The important transition is:

```text
0 → 1 → 2
    ↑
 current DFS
```

# ❌ Mistakes You Made

## 1. You used only 2 states

Initially you had:

```cpp
visited[vertex] = true;
```

and:

```cpp
else
    cycle = true;
```

### Problem

A visited node doesn't necessarily mean a cycle.

```text
0 → 1 → 2

3 → 2
```

When `3` reaches `2`:

```text
visited[2] = true
```

but there is **no cycle**.

That's why we need:

```text
1 = currently exploring
2 = completely finished
```

---

## 2. You used `prev_node`

You initially had:

```cpp
node != prev_node
```

That's useful for **undirected graphs**.

Course Schedule is **directed**, so parent tracking isn't the right approach.

Instead:

```cpp
visited[node] == 1
```

means cycle.

---

## 3. You started DFS only from `0`

You initially had:

```cpp
dfs_traversal(adj, 0, ...);
```

But the graph can be disconnected:

```text
0 → 10

3 → 18

5 → 5  🔴
```

DFS from `0` never reaches `5`.

So we need:

```cpp
for (int i = 0; i < numCourses; i++) {
    if (visited[i] == 0)
        dfs_traversal(i);
}
```

This checks **every disconnected component**.

---

## 4. You initially changed the wrong node to state `2`

You had:

```cpp
visited[node] = 2;
```

inside the loop.

But `node` is the **neighbor**.

You need:

```cpp
visited[vertex] = 2;
```

**after the entire loop**.

Why?

```text
DFS(vertex)
     ↓
state = 1
     ↓
explore ALL neighbors
     ↓
state = 2
```

Only after finishing every neighbor is `vertex` completely processed.

---

# 🧠 Final Mental Model

```text
          DFS(vertex)
               │
               ▼
        visited[vertex] = 1
               │
               ▼
       Explore every neighbor
               │
       ┌───────┴────────┐
       ▼                ▼
    state 0          state 1
       │                │
       ▼                ▼
     DFS()          🔴 CYCLE
       │
       ▼
    state 2
       │
       ▼
   Completely done
```

### Remember this:

> **`1` = I'm currently inside this DFS path**
> **`2` = I finished this node completely**

Therefore:

```cpp
visited[node] == 1
```

🔥 **Cycle**

```cpp
visited[node] == 2
```

✅ **Not a cycle**
